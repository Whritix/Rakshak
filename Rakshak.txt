1. PROJECT PROBLEM STATEMENT
======================================================================

Problem: Leverage AI to enhance naval (and army) analysts' ability to process
geospatial and multimodal data — satellite imagery, maritime sensor feeds,
drone footage, ground sensor reports — enabling faster threat detection and
mission planning within limited shipboard / field-deployed resources and tight
budgets.

The intended full system could combine:
- Earth-observation imagery: Sentinel-1 SAR, Sentinel-2 optical, Landsat,
  and commercial high-resolution imagery such as Maxar or Planet.
- Public overhead-image benchmarks: xView, xView3-SAR, SpaceNet, DOTA, FMoW.
- Maritime data: AIS tracks, radar tracks, satellite vessel detections, and
  simulated sensor feeds.
- Army data: drone/FMVs, ground-sensor reports, text reports, terrain, and GIS.
- Fusion metadata: timestamps, georegistration, sensor calibration, and source.

This project is deliberately scoped as a college hackathon prototype. It is
not a complete operational military or maritime system. It currently provides
a local xView object-detection demonstration and a separate Sentinel-2/Pipe V4
data explorer. It does not determine whether a detected object is a threat.

C. SATELLITE DETECTION TRAINING PIPELINE
- satellite_detector.py converts xView annotations into YOLO labels, cuts

  tile/overlap validation, confidence/IoU validation, output-folder creation,
  and a maximum-detections setting.
- Inference uses overlapping windows and global duplicate suppression to
  reduce duplicate boxes between neighboring tiles.
- Ultralytics warned that a tile contains more than 300 objects. The training
  run automatically adjusted validation max_det to 314; the code now sets a
  500-box per-tile ceiling for future training and inference.

Application flow:
1. Upload PNG/JPG/TIFF/GeoTIFF (maximum 512 MiB).
2. Scan image in overlapping 1024-pixel tiles with the existing xView
   one-class vessel checkpoint; overlapping boxes are merged by IoU.
3. Review model confidence and candidate boxes over the original image.
4. Analyst marks AIS association matched, unmatched, or unknown; only an
   explicit unmatched review adds +50 points.
5. A deterministic score includes unknown identity +10, same-image nearby
   cluster +20, and analyst-created zone +30; score is capped at 100.
6. View georeferenced model detections on the OSM map, score report, and
   highest-score-first review route. Route is not navigation guidance.
7. Select available local PipeV4 monthly CSVs, shown separately from model
   output. Empty MMSI stays unknown.

Important limitations:
- The checkpoint's held-out xView mAP@50 is 0.277; scene-specific performance
  varies substantially. Sentinel-2 has much coarser ground sampling distance
  than the overhead training imagery; one tested Sentinel-2 true-color scene
  yielded one candidate after contrast normalization, which is not a validated hit.
- Coordinates are available only if the input has valid raster georeferencing.
- The deterministic score is a review-priority heuristic, not probability or
  an operational threat judgment.
- Current user-created restricted zones are supported by API scoring; a map
  drawing workflow and zone CRUD UI remain future work.
- PipeV4 points currently appear in the threat map and table and are not
  AIS-ground-truth associations or detector labels. Up to 1,000 rows are read
  from an approximate regional rectangle; this is not an exact India border.
- Tile output is shown on the original-image overlay; there is no separate
  rendered prediction-image export yet.
- SQLite is the running store. PostGIS is only an optional schema; no Postgres
  service is configured or required for the local demo.
- OpenStreetMap background tiles require connectivity; API and model run local.

Suggested next phase:
1. Create held-out India coastal evaluation chips and expert-reviewed labels.
2. Add image-source/date filters, zone drawing/deletion, CSV import tuning,
   prediction export and analyst feedback capture.
3. Improve segmentation/rendering and tiled GeoTIFF geotransforms, then compare
   against Sentinel-1 SAR vessel benchmarks before making KPI claims.
